# V3 版本 prd
by DaXuan
Date: 2026-09-26
-------------------

## 多品牌色板（v1.2.0 已实现）
1. 对话框可选色板品牌：MARD/漫漫（默认）、Perler、Hama、Artkal（C 系列）
2. Perler 103 色 / Hama 92 色 / Artkal 174 色，数据来自 maxcleme/beadcolors（MIT）
3. Perler 色号为官网产品号（如 15179）
4. 色号排序支持纯数字色号（按数值排序）
5. 颜色匹配结果缓存（大图、多色板下提速）

## 界面（v1.2.0 已实现）
1. 菜单项、对话框、提示信息全部使用英文（Aseprite 菜单里中文字渲染过大）
2. 新增 色号字号(%) 设置：50–150，默认 100，只影响主图豆子上的色号文字

## 待办 / 候选

2. 渐变并色问题可通过 Floyd-Steinberg 抖动改善（未实现）
